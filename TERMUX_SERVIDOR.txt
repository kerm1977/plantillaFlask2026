============================================================
 GUÍA: CORRER LA TRIBU COMO SERVIDOR EN ANDROID CON TERMUX
============================================================

1. INSTALAR TERMUX
-------------------

Descarga Termux desde F-Droid (la versión de Play Store está desactualizada).

2. INSTALAR TODO AUTOMÁTICAMENTE
---------------------------------

Copia la carpeta del proyecto a `~/plantillaFlask2026` o clónala:

    cd ~
    git clone https://github.com/kerm1977/plantillaFlask2026.git

Luego ejecuta el instalador:

    cd ~/plantillaFlask2026
    chmod +x setup_termux.sh
    ./setup_termux.sh

Esto instala Python, librerías del sistema, dependencias, cloudflared,
levanta el servidor en tmux y activa el túnel si hay un token.

3. PROBAR LOCALMENTE
---------------------

El servidor corre en:

    http://localhost:5050

Abrí el navegador del celular en esa dirección.

4. CLOUDFLARE (INTERNET PÚBLICA)
---------------------------------

Si tenés un token de Cloudflare, guardalo en `cloudflared_token.txt`
dentro de `~/plantillaFlask2026`, o en `~/.cloudflared_token`.

El script `reiniciar_tribu.sh` levanta automáticamente el túnel.

    https://latribu.top

5. TMUX
--------

El servidor ya se inicia en sesiones de tmux:

    tmux ls
    tmux attach -t tribu_app      # Ver app
    tmux attach -t tribu_cloud    # Ver túnel
    tmux kill-session -t tribu_app

Para salir de tmux sin detener: Ctrl + B, luego D.

6. ARRANQUE AUTOMÁTICO AL PRENDER EL CELULAR
---------------------------------------------

Instala `termux-boot` desde F-Droid y abrilo una vez.

    pkg install termux-boot
    mkdir -p ~/.termux/boot
    cp termux_boot.sh ~/.termux/boot/start_latribu.sh
    chmod +x ~/.termux/boot/start_latribu.sh

Con eso, cada vez que encendés el celular levanta La Tribu.

7. ACCEDER DESDE OTROS DISPOSITIVOS
------------------------------------

En la misma red Wi-Fi:

    http://<IP-DEL-CELULAR>:5050

Para ver la IP:

    ifconfig

Busca la que empieza con 192.168.x.x o 10.x.x.x.

8. NOTAS IMPORTANTES
---------------------

- El puerto 5050 es HTTP local. Cloudflare le da HTTPS en internet.
- Termux debe tener batería "Sin restricciones" para no cerrar el proceso.
- Si se apaga la portátil, el celular mantiene la app viva.

9. COMANDOS RÁPIDOS
--------------------

    ./reiniciar_tribu.sh           # Reiniciar app y túnel
    python app.py                  # Correr manual (sin tmux)
    ifconfig                       # Ver IP del celular
    git pull                       # Actualizar
